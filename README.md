# 🌐 Plataformas de Hardware para Internet das Coisas (IoT)

> Repositório dedicado ao armazenamento, documentação e organização de roteiros práticos, relatórios, circuitos e códigos desenvolvidos durante as aulas de **Plataformas de Hardware para Internet das Coisas**.

---

## 👨‍🏫 Informações Acadêmicas

* **Disciplina:** Plataformas de Hardware para Internet das Coisas
* **Instituição:** Instituto Metrópole Digital (IMD) — UFRN

* **Objetivo Geral:** Estudar a arquitetura de microcontroladores, sensores, atuadores, circuitos eletrônicos básicos, protocolos de comunicação e desenvolvimento de sistemas embarcados voltados para soluções em IoT.

## 🗂️ Estrutura do Repositório e Roteiros

O repositório está organizado em diretórios modulares para cada atividade prática de laboratório. Cada pasta possui seus relatórios, arquivos de simulação e códigos-fonte correspondentes.

| Diretório | Descrição da Atividade | Principais Tópicos / Hardware |
| :--- | :--- | :--- |
| 📂 **[`01-roteiro-01`](./01-roteiro-01)** | Introdução à Eletrônica e Simulação de Circuitos | Leis de Kirchhoff, Circuitos Resistivos, Circuito RC, Simulador Falstad |
| 📂 **[`02-roteiro-02`](./02-roteiro-02)** | Semicondutores, Diodos e Portas Lógicas | Polarização Direta/Reversa, Sinal CA (1Hz), Portas Lógicas OR e AND com Diodos |
| 📂 *Novos Roteiros* | *Atividades em desenvolvimento...* | *ESP32, Sensores, Protocolos de Comunicação (MQTT/HTTP)* |

## 🛠️ Tecnologias & Ferramentas Utilizadas

### **Hardware & Componentes Eletrônicos**
* **Microcontroladores / Placas:** Arduino, ESP32
* **Componentes Passivos e Semicondutores:** Resistores, Capacitores, Diodos, LEDs
* **Sensores e Atuadores:** Sensores de temperatura/umidade, relés, chaves e interruptores

### **Software, Linguagens & Simulação**
* **Linguagens:** C, C++ (Arduino Framework)
* **Simulação de Circuitos:** [Falstad Circuit Simulator](https://www.falstad.com/circuit/)
* **IDEs & Ambientes:** Arduino IDE, VS Code, GitHub

---

## 🚀 Como Utilizar este Repositório

1. **Navegação:** Acesse cada pasta individualmente para visualizar o roteiro teórico, os relatórios de resolução em PDF e os códigos-fonte (`.ino` / `.cpp`).
2. **Simulações:** Nos `README` internos de cada atividade, você encontrará os links diretos para abrir e interagir com os circuitos montados no Falstad.
3. **Códigos:** Para compilar os arquivos de código `.ino`, utilize a Arduino IDE configurada com as placas correspondentes.
